\# LLM Security Audit



Audit de sécurité d'une application LLM (assistant interne avec RAG et outils) : construction d'une cible volontairement vulnérable (v1), audit selon l'OWASP Top 10 for LLM Applications, correction (v2) et re-test avec les mêmes attaques.



> \*\*Avertissement\*\* : cette application est volontairement vulnérable. Elle ne doit être exécutée qu'en local et ne jamais être exposée sur un réseau. Toutes les données, mots de passe et clés de ce dépôt sont fictifs.
